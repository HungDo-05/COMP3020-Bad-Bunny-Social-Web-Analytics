# The Social Pulse: Bad Bunny's Super Bowl Halftime Show

COMP3020 Social Web Analytics  
Western Sydney University  
Group 6, Trimester 3, 2026

## Project Overview

This project examines Bluesky discussions about Bad Bunny's Super Bowl halftime performance on 8 February 2026.

We collected posts using the Bluesky API and analysed changes in posting activity, comment content, clustering patterns and follower relationships.

## Data

The repository contains the datasets collected and processed for our group analysis, including posts, comments and follower network information.

## Analysis

The project includes R code for data collection, preprocessing, text analysis, K-means clustering, visualisation and network analysis.

## Software

The analysis was completed using R and RStudio. The main packages include tidyverse, tidytext, Matrix, cluster, igraph, ggplot2 and atrrr.

## Reproducing the Analysis

1. Download the repository.
2. Open the R Markdown files in RStudio.
3. Install the required R packages.
4. Check the dataset paths before running the reports.
5. Knit the R Markdown files to generate the analysis outputs.

The saved datasets are provided so the analysis does not require repeating the Bluesky API collection.
